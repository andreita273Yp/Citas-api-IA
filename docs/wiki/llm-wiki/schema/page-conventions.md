# Convenciones de páginas

## Clasificación de conocimiento

- **HECHO:** afirmación verificable en una fuente aprobada o en código/prueba inspeccionados. Debe citar origen.
- **DECISIÓN:** elección aprobada y vigente. Debe indicar responsable, fecha y fuente de aprobación. No presentar propuestas como decisiones.
- **PREFERENCIA:** elección estable de trabajo o presentación que no cambia el comportamiento del producto.
- **PREGUNTA ABIERTA:** asunto sin respuesta aprobada. No se resuelve por inferencia.

## Reglas de redacción

- Escribir síntesis, no transcripciones.
- Separar evidencia de inferencias.
- Usar enlaces relativos a fuentes RAW y páginas relacionadas.
- Marcar el estado de implementación cuando corresponda: `no iniciado`, `parcial`, `verificado`.
- Registrar en `wiki/log.md` cada INGEST, LEARN o LINT que modifique conocimiento.
