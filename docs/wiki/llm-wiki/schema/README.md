# Esquema de la LLM Wiki

La wiki usa tres zonas: `raw/` para fuentes inmutables, `wiki/` para síntesis mantenida y `schema/` para estas reglas operativas.

Antes de una operación, leer `../wiki/index.md`. Las convenciones de procedencia y de ciclo INGEST/QUERY/LEARN/LINT están en los documentos de este directorio.
