# RAW — Fuentes curadas

Este directorio conserva copias inmutables de fuentes aprobadas usadas por la wiki. Cada archivo debe tener su procedencia registrada en `../schema/source-provenance.md` y en `../wiki/log.md`.

No editar una fuente durante INGEST. Si la especificación cambia, añadir una nueva versión con procedencia y registrar la sustitución; no sobrescribir la versión anterior.

No almacenar archivos `.env`, secretos, tokens, credenciales ni PII.
