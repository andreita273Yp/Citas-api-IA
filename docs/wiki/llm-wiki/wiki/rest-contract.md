# Contrato REST

## Estado

**PREGUNTA ABIERTA — no diseñado ni implementado.** El PRD exige REST/JSON directo entre frontend y Spring Boot, pero no define endpoints, recursos, payloads, errores, paginación, filtros, serialización temporal ni versionado. Fuente: [PRD](../raw/approved/PRD-v1.0.md).

## Regla de evolución

Todo contrato aprobado debe documentar autorización, request, response, errores, validaciones, ejemplos sintéticos y compatibilidad. Un cambio de contrato requiere plan cross-repo, evidencia backend y evidencia frontend. Fuente: [AGENTS raíz](../../../../../AGENTS.md).

No crear un contrato a partir del diseño visual ni asumir un framework frontend antes de su aprobación.
